# Migration `2025_10_23_083817_create_unit_kerjas_table`

## Fungsi

`unit_kerjas` menyimpan unit organisasi konkret yang dipilih dalam `user_positions` dan menjadi scope aktivitas pengguna.

Contoh:

```text
Diskominfo
BKAD
SMP Negeri 01 Malang
Puskesmas Bareng
Bagian Hukum
Kecamatan Klojen
Kelurahan Bareng
```

## Perubahan dari struktur legacy

Kolom `skpd_id` legacy tidak dipertahankan karena datanya redundan terhadap `instansi_id` dan hanya digunakan sebagai pengelompokan tambahan.

Struktur baru menggantikannya dengan:

- `instansi_id` sebagai owner/ruang lingkup utama;
- `jenis` sebagai klasifikasi unit;
- `parent_id` sebagai hierarki eksplisit.

Dengan demikian, migration ini tidak lagi membutuhkan tabel `skpds`.

## Kolom

| `id` | Primary key internal |

## Relasi hierarki

```text
unit_kerjas.id
    1 ─────── N
unit_kerjas.parent_id
```

Contoh:

```text
Kecamatan Klojen
├── Kelurahan Klojen
├── Kelurahan Bareng
└── Kelurahan Kasin
```

Composite foreign key:

```text
(parent_id, instansi_id)
    → (id, instansi_id)
```

menjamin parent dan child berada di instansi yang sama.

## Candidate key penting

```text
uq_unit_kerjas_id_instansi (id, instansi_id)
```

Candidate key ini dipakai oleh:

1. self-reference parent unit;
2. composite foreign key `user_positions(unit_kerja_id, instansi_id)`.

Tujuannya mencegah posisi memilih unit milik instansi lain.

## Validitas unit

Unit dapat dipakai apabila:

```text
is_active = true
AND deleted_at IS NULL
AND (effective_from IS NULL OR effective_from <= hari ini)
AND (effective_until IS NULL OR effective_until >= hari ini)
```

## Check constraints

- `effective_until` tidak boleh lebih awal daripada `effective_from`.
- `parent_id` tidak boleh sama dengan `id`.

Circular hierarchy yang lebih panjang, misalnya A → B → A, harus dicegah pada service aplikasi karena tidak dapat dicegah hanya dengan check constraint sederhana.

## Query unit yang dapat dipilih

```php
UnitKerja::query()
    ->where('instansi_id', $instansiId)
    ->where('is_active', true)
    ->whereNull('deleted_at')
    ->where(function ($query) {
        $query->whereNull('effective_from')
            ->orWhereDate('effective_from', '<=', today());
    })
    ->where(function ($query) {
        $query->whereNull('effective_until')
            ->orWhereDate('effective_until', '>=', today());
    })
    ->orderBy('sort_order')
    ->orderBy('nama')
    ->get();
```
