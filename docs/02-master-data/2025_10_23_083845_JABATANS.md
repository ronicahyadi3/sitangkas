Satu jabatan dapat digunakan oleh banyak posisi pengguna. Satu pengguna dapat memiliki beberapa `user_positions` dengan jabatan yang berbeda atau unit yang berbeda.

## Arti `is_active`

`is_active = false` berarti jabatan tidak boleh diberikan pada posisi baru atau dipilih untuk konfigurasi baru.

Nilai tersebut tidak boleh menghapus atau mengubah histori `user_positions` yang sudah ada.

## Arti `is_system`

Jabatan inti dengan `is_system = true` tidak boleh dihapus atau diubah kodenya melalui UI biasa.

Perubahan terhadap jabatan sistem harus melalui migration/seeder yang direview.

## Authorization

Business logic harus menggunakan `kode` atau permission matrix, bukan numeric ID.

Benar:

```php
if ($position->jabatan->kode === 'KPA') {
    // ...
}
```

Lebih baik untuk aksi granular:

```php
Gate::authorize('document.update', [$document, $activePosition]);
```

Salah:

```php
if ($position->jabatan_id === 6) {
    // ID dapat berbeda antar-environment.
}
```
